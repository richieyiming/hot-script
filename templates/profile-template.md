# 账号知识库填写模板

请根据自己的真实情况填写。没有的信息可以暂时留空，不要编造。

## 一、基本定位

- 我的行业：
- 我的产品或服务：
- 我的主要平台：
- 我的目标用户：
- 我希望用户记住我的一个标签：

## 二、目标用户

- 他们目前处于什么阶段：
- 他们最常遇到的三个问题：
- 他们最想获得的结果：
- 他们通常会搜索什么词：
- 他们最担心什么：

## 三、个人经验

- 我做过哪些与行业相关的事情：
- 我踩过哪些坑：
- 我验证过哪些方法：
- 哪些内容可以公开：
- 哪些内容禁止公开：

## 四、表达风格

- 我平时说话偏正式还是口语：
- 我喜欢使用的表达：
- 我不喜欢使用的表达：
- 我希望呈现的形象：
- 可以参考的三段本人原话：

## 五、内容与转化

- 我的主要内容方向：
- 我能免费提供什么：
- 我的付费产品或服务：
- 希望用户看完内容后做什么：
- 不允许出现的承诺或导流方式：

## 六、隐私边界

以下内容不要填写：

- 密码和验证码
- 身份证、银行卡等身份信息
- 客户隐私和未公开合同
- API Key、Cookie或其他账号凭证
- 不希望出现在公开内容中的个人经历
