# 事件与成文模板、模拟示例

## 模板

事件卡：ID、发生时间、记录时间、情境、原话、实际动作、结果证据、source_locator、隐私。
解释卡：当时感受、事后解释、真实冲突、唯一观点、适用条件、反例、确认状态。
内容：人群、平台、标题、正文、引用细节、待补事实。
回流：事件ID→观点ID→内容ID，状态草稿/已确认/已做/已发布/已复盘；未知不得自动跳状态。

## 模拟示例

输入：“今天客户问我能不能帮他做十张海报。我先问给谁看，他说没想过。后来我们先定了受众，海报还没做。”
候选观点：需求还没说清楚时，先确认给谁看。适用新项目brief不完整时；不适用已有完整brief却重复追问的情况。
朋友圈草稿：今天客户问我能不能帮他做十张海报。我先问了一句：给谁看？他说还没想过。我们最后先把受众定下来，海报还没动。有时候开工前多问这一句，后面的内容才知道往哪写。
事件卡：原句来自模拟输入；海报未完成、结果未知；最后一句为候选判断，不声明真实返工减少或成交提升。上述“今天”只有在用户本次明确今天时才能沿用。
