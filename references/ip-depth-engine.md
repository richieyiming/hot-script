# IP炼金师 · 深层IP模块

用于把“一个经历做成一张资产卡”进一步升级为“从经历中提炼人格、世界观和长期表达母题”。默认不替用户包装人设，只从真实材料中提取。

## 1. 人格密度

判断一条内容里有多少东西“换一个人就说不出来”。优先提取：

- 亲历细节
- 当时真实反应
- 旧判断与新判断
- 犯错与修正
- 选择与代价
- 独特比喻和口头表达
- 用户真正坚持或拒绝的东西

知识正确不等于IP成立。人格密度越高，内容越像“这个人”，而不是通用答案。

## 2. 认知变化卡

任何有价值的经历，尝试记录：

- 我以前怎么想
- 什么事情让我停下来
- 我后来发现哪里不对
- 我现在怎么想
- 为什么发生变化
- 这个新判断在哪些条件下成立

“公开修正自己”是高价值IP资产，不把认错视为削弱权威。

## 3. 世界观聚类

单张资产卡完成后，检查它是否与用户已有观点形成重复母题：

- 我反复在乎什么？
- 我反复反对什么？
- 我看商业/人生/关系时常用什么逻辑？
- 哪些观点在不同事件中反复被验证？

同一观点在多个真实场景出现时，升级为“世界观母题”，而不是继续当零散内容。

## 4. 题材不必垂直，世界观必须一致

不要强迫一个IP只讲单一题材。允许商业、AI、创业、成长、家庭、生活等多主题共存，前提是：

- 解释世界的方式稳定
- 价值观稳定
- 核心人设来自真实经历累积
- 观众能感到“虽然题材变了，但还是这个人”

## 5. 过程型自我暴露

优先记录“认知形成过程”，而不只记录最终答案：

`发生了什么 → 我第一反应是什么 → 我哪里没想明白 → 我查了/做了什么 → 我为什么改判断 → 现在怎么看`

自我暴露不等于泄露隐私；重点是把认知形成过程公开出来。

## 6. 人格连接词

不要机械删除所有看似“没信息量”的表达。保留有价值的：

- 玩笑
- 自嘲
- 口头反应
- 真实犹豫
- 小跑题
- 生活细节

它们可能承担人格、情绪、现场和关系价值。只有完全不服务内容和人格时才删除。

## 7. 母题续矿

一张高价值资产卡不要只对应一条内容。继续生成：

- 同观点的新故事
- 反例
- 评论区追问
- 旧判断/新判断对照
- 不同人群版本
- 不同场景版本

目标是建立“少数核心观点 × 多个真实场景”的长期表达体系。

## 8. 商业承接检查

IP资产与商业连接时，优先遵守：

`内容 → 认知 → 信任 → 用户真实实践 → 产品/服务`

不要硬插销售。产品最好是前面观点自然证明“为什么它应该存在”之后再出现。

## 9. 资产卡新增字段建议

在原资产卡基础上可增加：

- 人格细节
- 旧判断
- 触发事件
- 新判断
- 世界观母题
- 可公开程度
- 可续矿方向
- 与用户其他资产的连接

## 10. 边界

- 不替用户编造价值观
- 不把他人的经历写成用户亲历
- 不因为一条高赞内容就认定这是用户长期定位
- 不把“题材垂直”误当“IP稳定”
- 不用抽象标签代替真实故事与行为
