# 单张资产卡模板与模拟示例

## 模板

ID / 类型（观点、方法、动作或案例） / 用户原句 / 核心主张 / AI整理 / source_locator / 判断条件 / 动作 / 结果证据 / 适用条件 / 反例 / privacy / status / version。
需求匹配：身份 / 阶段 / 场景 / 问题与来源 / 对应供给资产ID / 小结果或内容角度 / 证据缺口。

## 模拟示例

用户片段：“昨天客户想让我们直接做海报，我先问投放给谁，结果连受众都还没定，所以先把人群确认了。”
卡片：主张候选“制作前先确认受众”；动作“问谁会看、遇到什么问题、看后做什么”；证据是用户自述，最终投放结果未知。适用初次需求不清的内容项目；已有明确brief时不必重做调研。需求匹配候选是刚接设计项目的自由职业者，角度“客户让你马上开工，先问这三个问题”；该人群匹配是AI推演，尚未实访。
