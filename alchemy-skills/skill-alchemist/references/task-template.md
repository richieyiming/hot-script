# 任务合同、验证模板与模拟示例

## 模板

目标/使用者；输入与样本；判断规则；分支；输出；验收；人工节点；异常退出；依赖与实际权限；留档。
载体选择：Prompt / Skill / 工具能力合同及理由。
测试：输入定位、模拟/真实、正常/缺失/异常、预期观察、实际输出、通过/失败/未验证、根因、版本。

## 模拟示例

需求：“把客户反馈整理成问题清单，不要自动回复。”
选择Prompt：一次性整理，无需外部工具。
完整Prompt：依据提供的反馈逐条提取实际问题，保留原句编号；按功能问题、使用困惑、建议、信息不足分类，模糊项不猜原因。输出编号、原句、类别、问题摘要、待补信息。没有反馈时请求输入，不编客户话；仅整理，不发送回复。交付前检查每个摘要可反查原句，所有未知被标明。
正常输入“1.页面打不开；2.希望加导出”→功能问题/建议；缺失输入→请求反馈；异常“它又这样了”→信息不足，不擅自写页面崩溃。此为模拟分支检查，不代表已运行客户系统。
