# 炼金师系列 · 公开体验版

由黄一铭维护。每个技能独立解决一个小任务，不要求提供作者的个人知识库，也不保证流量、收入或经营效果。公开版提供完整的小任务流程；完整版中的私有资产、客户案例、报价和完整诊断规则不随包发布。

| 技能 | 这次能拿到的结果 | 入口 |

## 怎么用

先试灵感炼金师：提供一段真实经历，说明谁看、发在哪。每个目录中的SKILL.md是入口，references提供模板、明确标模拟的示例和回流规则，agents提供显示信息。可把整个对应目录放进支持Skill的工具的技能目录；没有该能力时把SKILL.md和相关参考交给AI按任务执行。

不要同时安装同ID的公开版和自用版到同一位置；已有完整版先备份，或在独立环境试公开版。运行环境无联网/文件写入时仍能处理文本，但必须如实说明未执行外部动作。

关联：[热点炼稿](../SKILL.md) · [小红获客宝](https://github.com/richieyiming/xhs-huokebao)

这些流程是用于设计和验证的方法，不是已实证经营规律；所有示例明确为模拟，不是客户案例。用户真实结果回来后再迭代。没有附带或复刻第三方课程、原文Prompt及源文件。
