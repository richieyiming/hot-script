# 初诊模板与模拟示例

## 模板

问题卡：部门/岗位、任务、当前问题、影响指标、证据、未知项。
四层：层 / 现有做法 / 证据 / 缺口 / 下一步。
验证草案：任务 / 输入样本 / 原方式 / 成功与停止条件 / 人工接管 / 负责人 / 权限 / 周期 / 成本状态 / 复盘口径。

## 模拟示例

输入：一家服务公司每周整理客户咨询，员工说“分类很慢”；没有提供用时、样本或数据授权。
输出：问题候选是咨询分类耗时；钱路候选为流程成本，金额待补。工具层需检验分类能力；知识层缺分类定义与匿名样本；流程层需明确谁复核不确定记录；组织层需负责人和数据权限。先取得少量覆盖正常/模糊情况的匿名样本，与原人工分类比较质量、总用时和介入量；成功/停止阈值由负责人提出。状态：初诊草案，未实施，ROI未知。
