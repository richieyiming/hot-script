# 最小产品模板与模拟示例

## 模板

能力与证据 / 人群与问题 / 现状 / 目标状态 / 路径 / 最小交付物 / 包含与不包含 / 输入与协作 / 周期状态 / 验收 / 异常处理 / 卖点 / 名称候选 / 价格状态 / 关键假设与验证。

## 模拟示例

输入：“我帮朋友把乱的面试材料整理过一次，但还没收费。”
候选产品：“面试材料梳理包”；交付“经历清单、岗位对应证据与表达提纲”，不包含保证录用或替代招聘决定。目标人群候选为准备面试但资料混乱者；需要本人提供真实经历和岗位要求；验收看经历事实是否正确、材料是否能用于练习。价格与交付周期待确认。先找符合条件的人体验一个小样，记录使用阻力和支付意向；现有一次帮助只说明做过，不证明产品需求已验证。
