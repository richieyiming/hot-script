# 热点炼稿 · 热点 × 知识库 → 口播稿

> 创始人 IP / 个人 IP 的口播稿系统。把你行业的热点，炼成有你自己观点、能直接拍的口播稿。

---

## 它解决什么问题

老板做短视频最大的痛：热点天天有，但抄来的稿子不是「你」，AI 写的稿子没你的经历。

热点炼稿 = 加工机：

**热点 + 事件 + 你的知识点 + 你的核心价值点 = 一条能直接拍的口播稿**

---

## 每次出稿你拿到什么（七件套，缺一不可）

1. **爆款标题**：1 主 + 2 备选（不同风格）
2. **话题标签**：≥5 个，按优先顺序排列
3. **口播稿**：1 分钟 + 3 分钟两版都出（按你的语速定字数，可只要一版）
4. **事实索引**：每条说法都能核到出处（来源名 + 可点击链接 + 可信度标注），绝不编数据
5. **真实配图**：事件真实图（1 分钟版 ≥4 张，找不到就用净化文字截图兜底）
6. **观点可视化视图**：浅色极简风卡片，同一篇内颜色 100% 统一，贴视频中间不被字幕挡
7. **交付包**：单文件 HTML，读稿 → 一键复制 → 一键存图 → 剪视频，一条龙

> **交付硬闸门**：写完稿先逐件清点这七件，少一件就是没完成；确实做不到的（图抓不到等）会明确告诉你缺什么、为什么、用什么替代——绝不静默交残包。

> **合规硬闸门**：出稿前必过「违禁词 + 违禁品类 + 广告法」三道自检，并附一张**合规自检表**（本次替换了哪些词：原话 → 改后）。拿不准的会显式报备风险点，不让你踩限流和封号的坑。

## 不知道拍什么？

跟热点、跟爆款之外，v1.1 给了两套装置：

**① 九宫格选题法（解决「有话说」）**：中心格填你的人群、外 8 格填痛点，中心 × 任意外格 = 一条文案，8 条起步、痛点再拆一层到几十条——把「今天拍什么」从拼灵感变成跑结构。

**② 矛盾点爆款法（解决「说得爆」）**：在你的赛道里找到「两个都想要、但互相打架」的东西并亮出来——学习 vs 想睡、想健身 vs 没场地。冲突自带张力，观众会替你把视频看完。判断标准一句话：**两个都要、一个都不能放，才叫矛盾；一个对一个错，叫批评。**

> 这套的样本很硬：一个高中生账号，只发了十几条视频、大部分是爆款——粉丝量极小却条条爆，说明爆的不是账号权重，是内容里装了「矛盾点」这个可复制开关。

直接对 AI 说：「我不知道今天拍啥」「帮我批量出一周的选题」，或「帮我找找我这个赛道的矛盾点」就行。

## 会不会违规被限流？

每条稿子在交付前都要过一遍**平台合规自检**，覆盖抖音 / 快手 / 小红书 / 视频号 / B站 / 知乎的常见违禁词和违禁品类，以及《广告法》里的绝对化用语红线：

- **广告法绝对化用语**：最 / 第一 / 唯一 / 顶级 / 国家级 / 100% / 全网最低 / 销量第一 —— 命中就改
- **高风险品类**：医疗医美、保健食品、金融理财、教育培训、房地产、招商加盟 —— 不谈疗效、不承诺收益、不承诺包过
- **绝对禁区**：烟草 / 赌博 / 彩票预测 / 代孕 / 封建迷信 —— 任何角度都不碰
- **导流话术**：加微信、二维码、站外链接 —— 一律改成平台内动作（评论关键词 / 主页 / 关注）
- **多平台分发**：按最严的那个平台改，一份稿子发出去不翻车

改法不是把话改软，是**把话改具体**：「最好的方法」→「我试下来最顺手的」，「稳赚」→「风险在这三处，我提前踩过」。数字、过程、真实案例比极限词更有说服力，而且零风险。

## 为什么不是通稿

热点边界 **不写死** —— 系统先读你的知识库，推出你做什么行业、观众是谁，再圈出你该追哪几类热点。

做餐饮的拿到的热点，和做教育的完全不一样。
