# 热点炼稿 · 热点 × 知识库 → 口播稿

> 创始人 IP / 个人 IP 的口播稿系统。把你行业的热点，炼成有你自己观点、能直接拍的口播稿。

---

## 它解决什么问题

老板做短视频最大的痛：热点天天有，但抄来的稿子不是「你」，AI 写的稿子没你的经历。

热点炼稿 = 加工机：

**热点 + 事件 + 你的知识点 + 你的核心价值点 = 一条能直接拍的口播稿**

---

## 每次出稿你拿到什么

1. **爆款标题**：1 主 + 2 备选 + 话题标签
2. **口播稿**：1 分钟短版 + 3 分钟长版（按你的语速定字数）
3. **事实索引**：每条说法都能核到出处，绝不编数据
4. **真实配图**：事件真实图（找不到就用净化文字截图兜底）
5. **思维导图**：方形图，贴视频中间不被字幕挡
6. **交付包**：读稿 → 一键复制 → 一键存图 → 剪视频，一条龙

---

## 为什么不是通稿

热点边界 **不写死** —— 系统先读你的知识库，推出你做什么行业、观众是谁，再圈出你该追哪几类热点。

做餐饮的拿到的热点，和做教育的完全不一样。

---

## 装之前（重要，60 分钟）

先做「建库」：打开 `setup-guide.html`，跟着路标地图走，AI 问你答，60 分钟攒出你的知识卡片。

**库是空的，这机器白装。**

---

## 怎么装

1. 在 WorkBuddy 里导入 `hot-script.zip`
2. 装完第一句话问：「帮我看看今天有什么适合我的热点」
3. 系统会先看你的库，找到行业相关热点，再出稿
